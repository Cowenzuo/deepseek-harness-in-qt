## B1-1 并发竞态：killByPort 异步链互斥（L1）

**位置**：`src/process/dshprocessmanager.{h,cpp}`

**方案**：引入操作代际（generation）守卫所有异步回调：

```cpp
// dshprocessmanager.h private:
qint64 m_opGen = 0;                       // 每次 start/stop/restart 递增
void killByPort(std::function<void()> onDone, qint64 gen);

// dshprocessmanager.cpp：
void DshProcessManager::start() {
    if (m_state == State::Starting || m_state == State::Running)
        return;
    const qint64 gen = ++m_opGen;
    killByPort([this, gen]() {
        if (gen != m_opGen) return;       // 过期回调直接丢弃
        beginLaunch();
    }, gen);
}

void DshProcessManager::stop() {
    m_waiter->stop();
    m_pollTimer.stop();
    const qint64 gen = ++m_opGen;
    if (m_state == State::Running || m_state == State::Starting)
        setState(State::Stopping);
    killByPort([this, gen]() {
        if (gen != m_opGen) return;       // 迟到的 stop 回调不得打回 Idle / 删记录
        clearServiceSource();
        setState(State::Idle);
    }, gen);
}

void DshProcessManager::restart() {
    m_waiter->stop();
    m_pollTimer.stop();
    const qint64 gen = ++m_opGen;
    killByPort([this, gen]() {
        if (gen != m_opGen) return;
        beginLaunch();
    }, gen);
}
```

`killByPort` 内部：taskkill 完成计数的 lambda（`left` 闭包）也要带 `gen`，回调前判 `gen != m_opGen` 则放弃。

**验证**：服务运行中快速连点「停止→启动→停止」，最终状态与最后一次操作一致，进程数不重复。

## B1-2 更新流水线 Starting 阶段永久挂起（L2）

**位置**：`src/update/updatemanager.{h,cpp}`

**方案**：三个防护叠加：

```cpp
// updatemanager.h private:
QTimer m_startTimeout;                    // Starting 阶段超时兜底

// 构造：
m_startTimeout.setSingleShot(true);
connect(&m_startTimeout, &QTimer::timeout, this, [this] { fail(QStringLiteral("dsh 启动超时")); });

// beginStart()：
void UpdateManager::beginStart() {
    setStage(Stage::Starting);
    emit logOutput(QStringLiteral("重新启动 dsh..."), false);
    if (m_proc->isRunning()) {            // ① 前置检查：已是 Running 直接完成
        done();
        return;
    }
    m_startTimeout.start(60000);          // ② 超时兜底（与 ReadyWaiter 60s 一致）
    if (m_proc->state() == DshProcessManager::State::Stopping) {
        // ③ 上次 stop 未完成：等 Idle 再启动（一次性连接）
        connect(m_proc, &DshProcessManager::stateChanged, this, [this](DshProcessManager::State s) {
            if (s == DshProcessManager::State::Idle) {
                m_proc->start();
            }
        }, Qt::SingleShotConnection);
        return;
    }
    m_proc->start();
}

// done()/fail() 中：m_startTimeout.stop();
```

**验证**：更新期间手动点服务页「启动」后再跑更新 → 不再挂起；断网时 60s 后明确失败。

## B1-5 后台线程 use-after-free 与数据竞争（L5）

**位置**：`src/settings/settingsdialog.{h,cpp}`、`src/git/gitclient.{h,cpp}`

RepoSnapshot collectSnapshot(GitClient *git, const QString &sourcePath) {

} // namespace

## B2-7 checkout 非 origin 远程分支 detached HEAD（R11）

**位置**：`src/git/gitclient.cpp`

**方案**：统一「先本地、后基于远程建」模式：

```cpp
bool GitClient::checkoutBranch(const QString &name, QString *errorOut) {
    QString target = name;
    const int slash = target.indexOf(QLatin1Char('/'));
    if (slash > 0) {                                   // 远程跟踪分支 remote/xxx
        const QString local = target.mid(slash + 1);
        QString err;
        run({QStringLiteral("checkout"), local}, &err);
        if (err.isEmpty()) return true;                // 本地已有（或 DWIM 命中单 remote）
        err.clear();
        run({QStringLiteral("checkout"), QStringLiteral("-b"), local, target}, &err); // 基于远程建本地
        if (!err.isEmpty()) { if (errorOut) *errorOut = err; return false; }
        return true;
    }
    QString err;
    run({QStringLiteral("checkout"), target}, &err);
    if (!err.isEmpty()) { if (errorOut) *errorOut = err; return false; }
    return true;
}
```
